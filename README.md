# Northstar Realty — Enhanced HTML Version

## Run
Open `index.html` directly in your browser, or use VS Code Live Server.

## Pages
- index.html — redesigned homepage
- properties.html — searchable/filterable property collection
- property.html — property detail page
- contact.html — contact/inquiry page

## Notes
Images are loaded from Unsplash URLs, so an internet connection is needed for the demo images and Google Fonts.
This version is static HTML/CSS/JS. The original PHP form/database behavior has been replaced with front-end demo interactions.
